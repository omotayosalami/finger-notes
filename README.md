# Finger Notes
1. Create a GitHub repo and upload all these files (keep the folder layout).
2. Open the Actions tab. The Android job produces a downloadable app-debug.apk you can install on a phone.
3. The iOS job checks that the app compiles. To put it on a real iPhone or the App Store you need an Apple Developer account and signing certificates added to the workflow.
4. Change appId in capacitor.config.json to your own, e.g. com.yourname.fingernotes.
